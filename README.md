# PubMed 综述 PWA

这是一个纯前端、无后端服务的 PubMed 中文医学综述生成工具。用户在浏览器中填写自己的 DeepSeek API Key 和 My NCBI API Key，输入研究主题后即可完成 PubMed 检索、相关性筛选、综述生成和 Word 导出。历史记录和中间数据仅保存在当前浏览器中。

## 使用方法

1. 打开“设置”，填写 DeepSeek API Key 和 My NCBI API Key，并完成连接测试或明确跳过测试后保存。
2. 回到工作台，输入研究主题；默认使用“一键生成”模式，最大抓取量默认 300 篇。
3. 点击“一键生成综述”。相关性筛选最多并行 5 路请求，应用会继续完成大纲、正文和引用校验。
4. 任务完成后浏览器自动下载 DOCX。Word 文档包含综述标题、正文和正文实际引用的参考文献。
5. 如需检查或编辑检索式，可切换为“确认检索式”模式；历史页面可重新导出 Word、JSON 和 CSV。
